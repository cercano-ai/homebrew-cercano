# Legacy Cercano Homebrew tap

This tap is superseded. Install the current standalone Cercano agent with:

```sh
brew install cercano-ai/tap/cercano
```

The canonical tap is [cercano-ai/homebrew-tap](https://github.com/cercano-ai/homebrew-tap).
Its current formula requires Apple Silicon and macOS 12 or later. Historical
Intel Mac and Linux entries here do not imply support in the current standalone
formula.

This repository retains its history and old formula for reference. It is not an
active installation or publishing destination, and no legacy-platform automatic
upgrade bridge is provided. See the [current agent guide](https://github.com/cercano-ai/Cercano)
for supported distribution options. Do not delete your configuration or saved
conversations when changing installation methods.
